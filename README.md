# Preschool Concept Game

**Version 1.0**

A simple interactive preschool game for practicing size, quantity, comparison, and compound words with pictures, sound, and short spoken directions.

## Learning areas

- Big / Small / Little
- Many / Few
- More / Less / Equal
- Compound Words

The first release contains 40 short activities. It includes spoken directions, a repeat button, positive/neutral feedback, and spoken compound-word answers.

## Privacy

The game does not ask for, collect, or store child names or other identifying information.

## Use

Open `index.html` through GitHub Pages. The presentation page is `about.html`.
